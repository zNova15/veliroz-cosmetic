# Veliroz Cosmetic

Sub-marca de skincare del ecosistema Veliroz (Cajamarca + Lima, Perú).

## Stack

- **Next.js 16.3** App Router + React 19 + TypeScript
- **Tailwind CSS 4** (CSS-first `@theme` config)
- Fuentes: Fraunces (serif display) + Inter (body) + JetBrains Mono (precios/ingredientes)
- **Supabase** — proyecto compartido `usfpzlxmmgruydqbymsx` (Firebase JWT + RLS)
- **Deploy**: Vercel Hobby en `veliroz.com/cosmetic` (rewrite desde Cloudflare)

## Scripts

```bash
pnpm dev       # dev server con turbopack
pnpm build     # producción
pnpm start     # servir build
```
